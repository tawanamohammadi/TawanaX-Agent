# 🤝 Contributing to TawanaX-Agent

Thank you for your interest in contributing to TawanaX-Agent! 

## 🚀 Quick Start

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/YOUR_USERNAME/TawanaX-Agent.git`
3. **Create** a branch: `git checkout -b feature/amazing-feature`
4. **Make** your changes
5. **Commit**: `git commit -m "Add amazing feature"`
6. **Push**: `git push origin feature/amazing-feature`
7. **Open** a Pull Request

## 📋 Guidelines

### Code Style
- Follow PEP 8 for Python code
- Use meaningful variable and function names
- Add docstrings to functions and classes
- Keep functions focused and small

### Commits
- Use clear, descriptive commit messages
- Start with a verb: "Add", "Fix", "Update", "Remove"
- Reference issues when applicable: `Fix #123`

### Pull Requests
- Describe what your PR does
- Reference any related issues
- Ensure CI checks pass
- Be responsive to feedback

## 🤖 Agent Development

When adding or modifying agents:
1. Follow the existing agent structure
2. Implement chain of thought logging
3. Add safety checks via Saloumeh
4. Update documentation

## 🐛 Reporting Issues

- Use the issue template
- Provide reproduction steps
- Include environment details
- Be respectful and constructive

## 💜 Code of Conduct

Be kind, respectful, and inclusive. We're all here to learn and build together.
