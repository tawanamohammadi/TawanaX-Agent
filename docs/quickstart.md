# Quickstart

```bash
git clone https://github.com/tawanamohammadi/TawanaX-Agent.git
cd TawanaX-Agent
python -m venv .venv && .venv\Scripts\activate  # Windows
python -m venv .venv && source .venv/bin/activate  # macOS/Linux
python src/agent.py
```
