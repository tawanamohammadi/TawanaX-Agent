## 🧠 Philosophy

> **"Agents decide. Agents execute. I review."**
> — Tawana Mohammadi, Multi-Agent Engineer

TawanaX-Agent represents a paradigm shift in AI-assisted development. Instead of single-purpose tools, we orchestrate **multiple specialized agents** that collaborate, reason, and execute complex workflows autonomously.

The human (Tawana Mohammadi) serves as the **Final Reviewer** — agents make decisions and execute, while the engineer provides strategic oversight and final approval.

## 🤖 Agent Ecosystem

| Agent | Role | Description |
|-------|------|-------------|
| 🌳 **TawRoot** | Core Brain | The master orchestrator. Manages multi-agent workflows, chain of thought reasoning, and multi-stage execution. The autonomous brain of TawanaX. |
| 💜 **Saloumeh** | AGI Core | Named after our beloved supporter. Handles advanced reasoning, safety checks, and quality review. The heart and energy of the project. |

## 🎯 Key Features

- **🧠 Chain of Thought** — Agents reason through problems step-by-step
- **🔄 Multi-Stage Pipelines** — Planner → Executor → Reviewer → Finalizer
- **🤝 Agent Collaboration** — Agents communicate and delegate tasks
- **👁️ Human-in-the-Loop** — Final review by human engineer
- **📊 Observability** — Full tracing of agent decisions and actions
- **🔒 Safety First** — Built-in safety checks via Saloumeh agent

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/tawanamohammadi/TawanaX-Agent.git
cd TawanaX-Agent

# Create virtual environment
python -m venv .venv

# Activate (Windows)
.venv\Scripts\activate

# Activate (macOS/Linux)
source .venv/bin/activate

# Run the agent
python src/agent.py
```
